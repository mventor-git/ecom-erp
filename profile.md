## 1. Project Overview

Comfort Sign is a self-hosted, modular ERP platform for **physical therapy & sports equipment**, evolved from an e-commerce store into a complete business operating system. It manages the full lifecycle: supplier procurement → warehouse storage → customer orders → delivery → returns. It runs entirely from a personal PC with **zero monthly hosting costs** ($0/month, plus Stripe/Paymob transaction fees). The Next Era (v2) goal: be best-in-class across four surfaces — customer web, admin ERP web, mobile web (PWA), and Android (APK).

## 7. Architecture

- **Style:** Modular ERP — e-commerce + ERP sections cleanly separated; services-only module communication.
- **Events:** Immutable event system (27+ event types); timeline generated from events; audit trail on all mutations.
- **Inventory:** Derived from movements only (11 types); never updated directly; products ≠ inventory (products describe, inventory locates).
- **Documents:** Never deleted; cancelled is a status; every document has number, status, timeline, history, audit log.
- **QR:** Codes identify resources (product/variant/shipment/PO/SO/location/serial); same QR shows permission-scoped data.
- **RBAC:** 6 roles / 26 permissions; backend always re-validates; never trust the frontend.
- **Data layer:** SQL.js (no native deps), file-based sessions, in-memory TTL cache for product listings — single-process assumption.
- **Frontends:** Separate admin frontend; customer site has no admin routes.
